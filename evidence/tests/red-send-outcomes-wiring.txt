The mutation run then left four mutants alive. A case was added to a
test above for each, written after the code it checks: PlainFileTest's
"two set aside in the same millisecond each keep their own name", and
three tightened JournalTest cases (a stop's outcomes on disk before any
later save, a marker that never reached disk is not kept, and a failed
write kept as a change to save next time). A local mutation run showed
the first three killed. The last case makes the write itself fail rather
than the folder sync; the mutation job in CI shows whether it kills its
mutant.
