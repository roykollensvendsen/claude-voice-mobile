# claude-voice-mobile

How a change is made here is in [CONTRIBUTING.md](CONTRIBUTING.md). What an
assistant must and must not do in this repository is in
[AGENTS.md](AGENTS.md). Both apply to every Claude session here.

The agent protocol and the plugin format this app speaks are specified in
[claude-voice](https://github.com/roykollensvendsen/claude-voice), in
`decisions/ADR-CV-006` and `decisions/ADR-CV-007`. A change to either starts
there, never here.
